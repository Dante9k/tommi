# 朱果宣传与下载页

品牌中文名为「朱果」，英文名为 **Tommi**，作为小番茄的亲切昵称。官网与当前嵌入短片统一使用此名称；1.1.17 起新安装包统一命名为 Tommi，历史下载继续保留。

无需前端依赖的中英双语静态网站。奶油白、浅砂色与暖灰的克制视觉，包含真实应用渲染的桌面交互示意、写作/阅读/创作场景、三步操作、键盘可操作的节奏预览、35 秒中英文产品短片、设计理念、常见问题及 EXE / ZIP 下载。品牌介绍采用通用桌面应用定位，Mac 与 Windows 的平台要求在下载及 FAQ 中说明。尊重系统减少动态效果设置。

短片沿用页面的暖色背景，取消独立深色版块和厚重外框，以轻微暖光承接竖屏画面。未播放时展示简洁的封面播放入口，开始播放后使用浏览器原生控制；没有 JavaScript 时直接保留原生控制。

语言按钮同步更新正文、页面标题、描述、图片说明、无障碍标签及短片；选择保存在本机。`?lang=en` / `?lang=zh` 可分享指定语言，优先于已保存的偏好。Mac 应用跟随系统中英偏好；Windows 1.1.19 起支持应用内中英文即时切换，FAQ 已说明网站与应用语言设置相互独立。

下载区提供两个平台的入口：Windows 下载由构建生成；Mac 直接链接已核实的 GitHub Release `macos-v1.1.16`（DMG、ZIP、SHA-256），适用于 macOS 13+ 的 Apple Silicon 与 Intel。该 Mac 发布在 GitHub 标为预发布，页面相应标注「预览版」。更新 Mac 链接前应先确认对应发布及资产已经存在。Mac 的登录时启动默认开启，可在偏好设置关闭，与 Windows 的行为不同。

`media/` 中的公开素材随仓库保存，并明确加入部署白名单。两部短片来自已有 1080×1920 的 V2 故事版，压缩为 720×1280 H.264，原有 AAC 音轨保留，使用 faststart 支持边载边播。WebP 海报与透明产品图经过尺寸优化。无需在网站构建时重新渲染影片。视频保留竖屏比例，点击才下载播放；页面离开可视区域或切换语言时暂停，提供原生全屏/音量/进度控制、文字故事摘要和单独打开链接。本地预览支持视频 Range 请求。

## 本地预览

在仓库根目录运行 `node website/serve.cjs`，打开 http://127.0.0.1:4173。预览服务仅监听本机，且只公开白名单内文件。

## 生成下载与部署包

仅修改网站、且当前 VERSION 的应用包已在 `dist/` 中生成时，可运行 `./scripts/build-website.ps1 -UseExistingApplicationPackage`。该模式先验证现有 EXE 和 ZIP 的 SHA-256，再生成网站包，不重编译桌面程序。

在 Windows 上运行 `./scripts/build-website.ps1`。它复用 `./package.ps1` 的统一打包流程：自动导出多尺寸品牌图标，执行应用构建和逻辑检查、真实控件渲染、便携包白名单与 SHA-256 校验，随后编译安装器、校验其内嵌压缩包，并在 `build/installer-preview.png` 输出真实安装控件的离线渲染图。普通打包与自动构建也会为每个版本生成同样的品牌安装包。版本号来自仓库 VERSION，网站构建自动更新网页下载链接与版本文案。

- `dist/Tommi-<版本>-Setup.exe`：图形安装器；默认安装到当前用户的 LocalAppData/Programs/TomatoFocus/<版本>，也可输入完整路径或浏览选择其他可写的专用空文件夹。路径即最终位置。创建开始菜单快捷方式，可选创建桌面快捷方式。
- `dist/Tommi-<版本>-win-x64.zip`：免安装便携版。
- `dist/Tommi-website-<版本>.zip`：仅包含公开网页、图片、下载文件及 SHA-256 清单。

安装器不提权、不添加开机自启、不启动应用、不修改计时状态、不覆盖非空目录或内容不同的已有安装；无权写入时可重新选择文件夹。更新已有快捷方式前保存备份。当前为轻量安装器，不注册到 Windows「已安装的应用」，首次打开默认配置登录启动，设置中可关闭；卸载需先关闭该选项、退出应用后删除安装目录与快捷方式，用户状态默认保留。程序与安装器均未代码签名。自动验证覆盖内嵌载荷、自定义路径实际安装、文件保护及临时目录内的快捷方式；系统文件夹选择器和不同机器上的权限／显示缩放仍需手动验收。

## GitHub Pages

推送 `main` 后，`.github/workflows/pages.yml` 在 Windows 环境构建并校验网站包，只解压公开白名单中的文件到 Pages 发布产物，再部署到 `github-pages` 环境。服务器配置、开发脚本和本地文件不会进入官网。正式版本使用 `v<版本>` 标签触发 `.github/workflows/release.yml`，标签必须与仓库 `VERSION` 完全一致。

下载二进制不纳入 Git，通过上述构建命令生成。发布前应清理发布目录中不再需要的旧版本，避免无意分发旧包；本脚本不会删除已有下载。

## 网站验证

完成构建后，在 `website/` 执行 `npm install`，安装 `package.json` 中指定版本的浏览器测试依赖。预览服务使用 `npm start`；另一个终端在同目录执行 `npm test`。测试使用本机 Chrome，覆盖双语及语言记忆、桌面示意交互、键盘切换、视频播放/切换/暂停/拖动、真实下载、320–1440px 布局、减少动态效果及文字放大，并保存截图。可用 `WEBSITE_URL` 指定测试地址，`PORT` 指定预览端口。运行网站与桌面程序本身不需要 Node.js 或浏览器测试依赖。

## 部署模板

`deploy/` 提供 Ubuntu / Nginx 的内部验收、HTTPS、校验和回退模板。使用前将其中的 `example.com` 替换为自己的域名，并按 [部署说明](deploy/RUNBOOK.md) 配置服务器。仓库不包含具体服务器地址、DNS 账户信息或本机运维记录。

网站包通过明确的文件清单生成，只含当前版本下载和公开网页；`MANIFEST.sha256` 记录每个文件的哈希。发布时只上传网站 ZIP，不上传源码、部署配置或凭据。生成包不代表网站已部署或公网可用。

网站没有第三方 CDN、远程字体、登录、统计或后端接口，可直接托管于静态 Web 服务。
