# Tommi 1.1.22 for Windows

- Refined idle foliage: a relaxed curved vine straightens gradually under a downward pull. Staggered tomato leaflets have different sizes, curved petioles, soft lobes, veins and shaded folds; their orientation follows the branch as it bends.

- The idle branch now enters through the screen's top edge near the upper-right corner. Double-clicking the hanging fruit no longer opens it; pull down to pick it, or use the tray. A shorter pull still springs back.
- After one minute without interaction **while editing**, the branch extends to the stem. Gravity swings the attached tomato down and right as it shrinks and the branch reels upward, finally settling in the upper-right corner. Retraction adapts near screen edges to keep the fruit visible. Running timers, reminders and settings never trigger automatic idle.
- Motion stops rendering once settled. Empty transparent areas pass mouse input through to the desktop. Reduced system motion skips transitions. Existing durations, settings, bilingual UI and restored countdowns remain compatible.

Download `Tommi-1.1.22-Setup.exe` or the portable `win-x64.zip`. Quit the running app through its tray menu before upgrading. Installation does not automatically launch the app. Launch at login remains optional and defaults on at first launch. The internal executable remains `Tomato.exe` for compatibility.

Requires Windows 10/11 x64 and .NET Framework 4.8. App and installer are unsigned; archives exclude development verification tools and include SHA-256 checksums. macOS remains at 1.1.18; this hanging interaction is currently Windows-only.
