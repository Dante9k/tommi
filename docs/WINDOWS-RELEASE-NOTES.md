# Tommi 1.1.20 for Windows

- A small tomato now hangs from a leafy branch in the upper-right corner when idle. Pull down to pick it; the branch bends and retracts as the tomato grows into the editor. Release a shorter pull and it springs back. Double-click the fruit or tray icon to open it too.
- After one minute without interaction **while editing**, the branch reaches the stem, lifts the tomato home and lets it sway twice. Running timers, reminders and settings never trigger automatic idle.
- Motion stops rendering once settled. Empty transparent areas pass mouse input through to the desktop. Reduced system motion skips transitions. Existing durations, settings, bilingual UI and restored countdowns remain compatible.

Download `Tommi-1.1.20-Setup.exe` or the portable `win-x64.zip`. Quit the running app through its tray menu before upgrading. Installation does not automatically launch the app. Launch at login remains optional and defaults on at first launch. The internal executable remains `Tomato.exe` for compatibility.

Requires Windows 10/11 x64 and .NET Framework 4.8. App and installer are unsigned; archives exclude development verification tools and include SHA-256 checksums. macOS remains at 1.1.18; this hanging interaction is currently Windows-only.
