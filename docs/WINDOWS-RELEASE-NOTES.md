# Tommi 1.1.19 for Windows

- Full English and Simplified Chinese interfaces for preferences, presets, tray status, reminders, wheel guidance, accessibility names and application messages.
- Right-click the tomato or tray icon and choose **Language → English / 简体中文 / System**. Switching is immediate and preserves your active timer, position, hidden state and reminders. System mode uses Chinese on Chinese Windows and English otherwise.
- The installer has independent **English / 简体中文** buttons. Changing its language preserves the selected folder and shortcut choice. Windows-owned folder dialogs follow the operating system language.
- Includes the Windows 1.1.18 wheel sound synchronization fix. Existing settings and countdowns remain compatible.

Download `Tommi-1.1.19-Setup.exe` for the graphical installer, or the `win-x64.zip` for the portable edition. Quit the running app through its tray menu before upgrading. Installation does not open the app automatically. Both editions configure launch at login when first opened; disable this setting before removing the app. The executable remains `Tomato.exe` and the existing settings folder is retained for compatibility.

Windows 10/11 x64 and .NET Framework 4.8 are required. The app and installer are unsigned. Packages exclude developer verification tools. SHA-256 files and release evidence accompany the downloads.

## 简体中文

- 新增完整英文界面，覆盖设置、预设、托盘状态、到时提醒、拨轮说明、无障碍名称与应用提示。
- 右键番茄或托盘图标，在「界面语言」选择 English、简体中文或跟随系统，立即生效并保存，不重置计时、位置、隐藏状态或提醒。默认中文 Windows 显示中文，其他系统语言显示英文。
- 安装器有独立的中英文按钮，切换后保留安装路径与快捷方式选择；Windows 自身的文件夹对话框使用系统语言。
- 包含 1.1.18 的拨轮音画同步修复，兼容原有设置与倒计时。

下载 `Tommi-1.1.19-Setup.exe` 安装，或使用 `win-x64.zip` 便携版。升级前请从托盘正常退出旧程序。安装完成后需要手动打开应用；两个版本首次打开都会配置登录启动，卸载前请先关闭此选项。为兼容旧版，内部程序名仍为 `Tomato.exe`，设置目录保持不变。

支持 Windows 10/11 x64，需要 .NET Framework 4.8。程序与安装包暂未代码签名；正式包不包含开发验证工具，并附 SHA-256 和发布证据。
