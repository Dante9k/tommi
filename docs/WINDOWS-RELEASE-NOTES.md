# Tommi 1.1.23 for Windows

- The returning branch first takes the tomato's weight, bends and lets it drop, then pulls it along an elastic arc into the distance.
- Position and apparent size now come from the same perspective camera. Branch taper, leaf size, delayed tilt and subtle distance shading follow the same motion instead of playing a separate shrink animation.
- Near the bottom edge the drop is gentler. Opening from the tray during return preserves the current pose for a smooth handoff. Active focus remains visible and never goes idle.

Download `Tommi-1.1.23-Setup.exe` or the portable `win-x64.zip`. Quit the running app through its tray menu before upgrading. Installation does not automatically launch the app. Launch at login remains optional and defaults on at first launch. The internal executable remains `Tomato.exe` for compatibility.

Requires Windows 10/11 x64 and .NET Framework 4.8. App and installer are unsigned; archives exclude development verification tools and include SHA-256 checksums. macOS remains at 1.1.18; this hanging interaction is currently Windows-only.
